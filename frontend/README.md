# Smart Forms - Frontend

Modern, interactive form builder & questionnaire interface built with **React JS** and **Tailwind CSS**.

## Tech Stack
- **Framework**: React 19 (JSX)
- **Styling**: Tailwind CSS v4 + Radix UI + Lucide Icons
- **Bundler**: Vite 8
- **Routing**: React Router v7
- **HTTP Client**: Axios (configured to connect to Spring Boot at `http://localhost:8088/api`)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The app runs at `http://localhost:5173`.

### 3. Production Build
```bash
npm run build
```
